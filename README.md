# E-Commerce Sales Analysis

## 📊 Project Overview

This project analyzes **5,000 e-commerce sales records** using **MySQL, SQL, and Excel** to identify sales performance, customer behavior, product trends, regional performance, and payment patterns.

The analysis converts raw sales data into meaningful business insights that can support data-driven decision-making.

## 🛠️ Tools & Technologies

* **MySQL** – Database management and SQL analysis
* **SQL** – Data querying and business analysis
* **Microsoft Excel** – Data cleaning, analysis, and visualization

## 🔍 Analysis Performed

The project covers the following key business metrics:

* Total Revenue
* Total Orders
* Total Quantity Sold
* Unique Customers
* Revenue by Product Category
* Revenue by Region
* Monthly Revenue Trends
* Payment Method Analysis
* Customer Rating Analysis
* Discount Analysis

### Key Insights

* Identified the **highest-performing regions** based on revenue.
* Identified the **top-performing product categories**.
* Analyzed **monthly revenue trends** to understand sales performance over time.
* Examined **payment methods** to understand customer purchasing preferences.
